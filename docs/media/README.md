# DipSignal Media

This folder is intended for app screenshots and demo videos.

Suggested files:
- `dashboard.png`
- `nifty-strategy.png`
- `etf-recommendations.png`
- `watchlist.png`
- `mutual-fund-opportunities.png`
- `alerts.png`
- `settings.png`
- `dipsignal-demo.mp4`

How to capture:
1. Run app with `npm run start`.
2. Open Android emulator/device.
3. Take screenshots from each key screen.
4. Record 30-60 sec walkthrough video.
5. Commit files here and update README links.
